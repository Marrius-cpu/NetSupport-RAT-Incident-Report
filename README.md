# NetSupport Manager RAT - Malware Packet Analysis

## Project Details
* **Host System:** Windows 11
* **Virtualization:** Oracle VirtualBox
* **Linux Distribution:** Lubuntu 24.04 LTS
* **Analysis Tool Used:** Wireshark
* **PCAP Used:** "2026-02-28 - TRAFFIC ANALYSIS EXERCISE: EASY AS 123" (https://www.malware-traffic-analysis.net/2026/02/28/index.html)

## Overview
This repository contains a Security Operations Center (SOC) incident report analyzing a practice PCAP exercise. This PCAP is a simulated attack by NetSupport Manager RAT, an unauthorized remote administration tool used for unauthorized access and data exfiltration. This project simulates a security compromise to an enterprise network segment (IP 10.2.28.0/24).
